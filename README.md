# revu-biz-fonts

biz.revu.net 웹 글꼴 조각 파일.

- 원본: Pretendard v1.309 (Kil Hyung-jin, SIL Open Font License 1.1) — https://github.com/orioncactus/pretendard
- 이 저장소의 파일은 원본을 글자 범위별로 나눈 **수정본**이며, OFL의 예약 이름 조항에 따라 글꼴 내부 이름을 `RevuBizSans`로 바꿨다.
- 라이선스: `OFL.txt` (SIL Open Font License 1.1). 글꼴 파일 단독 판매 금지.
